# Billboard & TikTok Music Trends with SQL

**Course:** Data 101, Data Engineering (UC Berkeley, Spring 2025), Project 0

**Question:** Which songs and artists dominate the charts, how long do hits last, and what's trending across Billboard and TikTok?

## Data
A PostgreSQL `billboard` database of weekly Billboard Hot 100 chart entries, plus TikTok trend data.

## What I did
I wrote SQL queries to answer chart-history questions:
- Recent hits and the songs with the **longest runs on the chart**.
- The longest-running **Top 10 hits of the 1970s**.
- **Top artists ranked by number-one hits.**
- Songs that are **popular on both Billboard and TikTok**, and a "Brat Summer" trend analysis.

## Skills and tools
PostgreSQL, SQL (joins, `GROUP BY` / `HAVING`, subqueries, CTEs, date filtering, ranking), JupySQL, pandas.
